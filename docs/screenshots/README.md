# Application screenshots

Place real screenshots captured from a running Drivebridge instance in this directory.

Recommended filenames:

- `home.png` — landing page
- `login.png` — sign-in page
- `dashboard.png` — authenticated dashboard
- `mcp-connect.png` — MCP setup instructions
- `mcp-consent.png` — authorization consent screen

Use a test account and redact personal information, email addresses, client identifiers, and other private data before committing screenshots.

The dashboard and consent page are authenticated flows; capture them only with a dedicated test account and a non-production environment.
